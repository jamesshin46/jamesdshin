# jamesdshin.com

The personal portfolio of **James Shin**, built like an artist page in a music-streaming app.

Each job, club, and school is an "album" you can play: its chapters are the stories behind the
work, and a player bar steps through them like a playlist. Visitors can like the pages they
enjoy, watch dance covers with live YouTube view counts, flip through a Recap of highlights, and
share a favorite song when they arrive.

**Live site:** [jamesdshin.com](https://jamesdshin.com)

Hand-coded with plain HTML, CSS, and JavaScript, hosted on GitHub Pages. View counts refresh
hourly through a GitHub Action; the guestbook and likes are stored in Supabase.
